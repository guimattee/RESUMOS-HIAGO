# RGR:
Desenvolvimento e teste em pequenos ciclos.
### Red-Green-Refactor - 
* **Red:** Escrever teste que falha;
* **Green:** Fazer o teste passar (com o mínimo de código) a partir de um código simples; 
* **Refactor:** Limpar e melhorar o teste.

# TDD e SOLID:
### SRP:
Se um teste é difícil de configurar, é um sinal que a função está tentando fazer coisas demais.

### DIP:
Para testar, é necessário injetar dependências, ajudando no desacoplamento.

### Clean Code:
Refatorar o código é aonde você aplica o CC.
