Quando precisa de alguma API externa, utiliza o TD para isolar o teste.
### Dummy:
Objetos passados para uma função só para preencher parâmetros.

### Stub:
Fornecem respostas pré-definidas.
EX: se programar ele pra falar sempre q tem arroz, ele sempre retorna arroz, mesmo se mudar.

### Mock:
Pré-programados com espera de resposta. Verificam se foram chamados de forma correta (verificação de comportamento).

### Spy:
Stub que registram como foram chamados.
EX: quantas vezes foram chamados e com quais argumentos foi chamado.
